# Roadmap

## Implemented

- Deterministic LED animation
- Normalized display curve
- WS2812 output adapter
- Automatic blackout on program exit
- Static preview renderer
- Unit tests and complete low-voltage build documentation

## Next physical iteration

- Assemble the LED ring and level shifter
- Photograph the build and document current draw
- Measure enclosure temperature after one hour
- Add a physical low-voltage power switch
- Record a demonstration video

## Optional software improvements

- Local browser dashboard
- Rotary encoder for exhibit modes
- OLED captions explaining the difference between the model and a real fusor
- Audio narration with captions

No roadmap item adds vacuum, high voltage, gas, radiation, or real fusor control.
